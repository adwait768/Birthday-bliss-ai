# Birthday Bliss 🎂✨

A colorful Android-first birthday planner with animated screens, saved birthdays, personalized photo posters, and optional music-backed greeting video export.

## Features
- Save birthdays, photos, relationship, notes and WhatsApp number
- Rich animated dashboard and poster studio
- Personalized poster headline/message with selectable gradient themes
- Choose an audio file for music-backed video export where the browser supports MediaRecorder
- Download poster artwork and open WhatsApp with a prefilled wish for review
- Local browser storage and JSON backup/restore
- Android WebView wrapper source

## Build APK
Open `android/` in Android Studio with Android SDK 35 installed, sync Gradle, then choose **Build > Build APK(s)**. Source is not a compiled or tested APK.

## Notes
- Still images cannot contain audio; music is for video export.
- Video recording support varies by device/browser.
- Background scheduled notifications are not implemented yet.
- WhatsApp/Instagram sending remains user-controlled.
